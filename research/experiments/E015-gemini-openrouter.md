# E015 Gemini API と OpenRouter の無料枠（2026-11-21）

- **目的**: 利用者の希望。無料で使える実モデルの経路を確かめ、Codex で得た結果が別モデルで再現するかを見る。
- **方法**: キーは `lab/homes/real/.env`（追跡対象外）。モデル一覧は各サービスの API で取得。`hermes -z "Reply with exactly: OK"` で疎通。
- **結果**:
  - OpenRouter: 無料・ツール対応・64k 以上のモデルは13個。`nvidia/nemotron-3-ultra-550b-a55b:free` は9秒で成功、費用0。`google/gemma-4-31b-it:free` は失敗（原因未調査）。キー情報は `is_free_tier: true`、`limit: 50`、4業務（約36リクエスト）実行後も使用額0・残り50。
  - Gemini: `gemini-3.8-flash` は 503（需要過多）の後、ストリームが180秒無応答。150秒制限の再試行でも完了せず。`gemini-3.6-flash` は成功したが104秒。Hermes の表示する推定費用は 0.0148 ドル。
- **注意**: Hermes の推定費用は定価での計算で、無料枠かどうかは反映しない。Gemini のキーが課金設定のあるプロジェクトのものなら実際に課金される。こちらからは判別できないので、Gemini は疎通2回にとどめた。
- **実験上の事故**: 1回目の疎通確認は、並行して動かした別スクリプトの `pkill` がゲートウェイを巻き込んで中断した。終了処理を pid ファイルで自分のプロセスだけに限定した。
- **次の行動**: 別モデルでの再現確認は OpenRouter の無料モデルで行う（結果は E016・E017）。Gemini は、キーが無料枠かを利用者に確かめてから。
